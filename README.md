# MovieCatalog

Буянин, БПИ263

Каталог фильмов на SwiftUI и SwiftData. iOS 17+.

Добавление, редактирование, удаление фильмов, статус просмотра и оценка от 0 до 5. Данные сохраняются между запусками. 0 означает отсутствие оценки.

Дополнительные задания:
- Поиск по названию и жанру и фильтр просмотра через `#Predicate` и `@Query`.
- Сортировка по дате, названию, году и рейтингу. Статистика по всему каталогу: количество фильмов, просмотренных и средняя оценка без учёта нулей.
- Модель `Genre` и связь с `Movie`. Правило удаления `.nullify`: фильмы сохраняются без жанра.
- Избранное, фильтр избранного, выбор нескольких фильмов, пакетная отметка просмотра и удаление.

Для запуска откройте `MovieCatalog.xcodeproj` в Xcode и выберите iPhone Simulator. Preview использует отдельное хранилище в памяти.
